# Facilita Psi

Aplicativo gratuito de agenda, presença, prontuário e financeiro para uma clínica de psicologia infantojuvenil.

**Este repositório contém apenas código.** Nenhum dado de paciente é guardado aqui: os dados ficam criptografados nos aparelhos da psicóloga e no Google Drive dela.

- [Especificação](docs/especificacao.md)
- [Arquitetura e decisões de tecnologia](docs/arquitetura.md)
- [Etapa 0: prova de conceito](docs/prova-de-conceito.md) (como rodar, publicar e testar)
- [Guia de configuração do Google Cloud](docs/guia-google-cloud.md)

## Desenvolvimento

Requer Node.js 24 LTS.

```bash
npm install
npm run dev     # http://localhost:5173
npm test
```
